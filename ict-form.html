HTML Forms

Learn how HTML forms collect user input using form elements, input types, and form attributes.

Reviewer Progress
Not completed

1. What Is an HTML Form?

An HTML form is used to collect user input. The input is often sent to a server for processing.

<form> form elements </form>
Remember: The <form> element is a container for different types of form controls.

2. The <input> Element

The <input> element is one of the most commonly used form elements.

Its appearance and behavior depend on the type attribute.

<input type="text" >
text Creates a single-line text input field.
radio Lets the user select one choice from a group.
checkbox Lets the user select zero or more choices.
submit Creates a button used to submit form data.
button Creates a clickable button.

3. The <label> Element

The <label> element defines a label for many form elements.

The for attribute of the label should match the id of the input it belongs to.

<label for="fname" > First name: </label> <input type="text" id="fname" name="fname" >
Key connection: label for="fname" → input id="fname"

4. Text Fields

<input type="text"> creates a single-line text input field.

<form> <label for="fname" >First name:</label> <input type="text" id="fname" name="fname" > </form>

5. Radio Buttons

Radio buttons allow a user to select ONE choice from a limited number of choices.

<input type="radio" name="language" value="HTML" > <label>HTML</label>
Memory tip: Radio = choose one.

6. Checkboxes

Checkboxes allow a user to select ZERO or MORE options.

<input type="checkbox" name="vehicle" value="Bike" > <label>Bike</label>
Memory tip: Checkbox = choose zero, one, or many.

7. Submit Button

<input type="submit"> creates a button for submitting form data.

<input type="submit" value="Submit" >

The form's action attribute specifies the form-handler that processes the submitted data.

8. Important Form Elements

<form>

Defines the form.

<input>

Creates different types of input controls.

<label>

Defines a label for a form control.

<select>

Creates a drop-down list.

<option>

Defines an option inside a select list.

<textarea>

Creates a multi-line text input area.

<button>

Creates a clickable button.

<fieldset>

Groups related form elements.

<legend>

Defines a caption for a fieldset.

9. Select, Option, and Textarea

Select

The <select> element creates a drop-down list.

<select name="subject"> <option value="math"> Mathematics </option> <option value="science"> Science </option> </select>

Textarea

The <textarea> element defines a multi-line input field.

<textarea name="message" rows="4" cols="30" > </textarea>

11. Form Attributes

Form attributes control how a form behaves and where submitted data is sent.

action

Specifies where the form data is sent.

method

Specifies the HTTP method used to send form data.

target

Specifies where to display the response.

autocomplete

Specifies whether autocomplete is enabled.

novalidate

Specifies that form validation should not occur.

enctype

Specifies how submitted form data should be encoded.

12. GET vs POST

Method Main Idea
GET Appends form data to the URL.
POST Sends form data in the HTTP request body.
<form action="/action_page.php" method="post" > ... </form>

13. Important Input Attributes

value

Specifies an initial value.

readonly

Makes the input read-only.

disabled

Disables the input.

size

Specifies the visible width of the input.

maxlength

Specifies the maximum number of characters.

min

Specifies a minimum value.

max

Specifies a maximum value.

multiple

Allows more than one value where supported.

required

Specifies that the field must be filled out.

placeholder

Provides a short hint describing the expected value.

pattern

Specifies a pattern the input value must match.

autofocus

Automatically focuses the input when the page loads.

14. The name Attribute

An input field needs a name attribute to have its value submitted with the form.

<input type="text" name="firstname" >
Important: If the name attribute is omitted, the value of that input field will not be submitted.

15. Input Form Attributes

These attributes can override certain <form> attributes for an individual submit button.

formaction

Specifies the URL where the form data is sent.

formenctype

Specifies how form data is encoded.

formmethod

Specifies the HTTP method used to submit the form.

formnovalidate

Specifies that the form should not be validated.

formtarget

Specifies where to display the response.

form

Specifies the form an input belongs to.

16. Complete Form Example

<form action="/action_page.php" method="post" > <label for="fname"> First name: </label> <input type="text" id="fname" name="fname" required > <br><br> <input type="submit" value="Submit" > </form>
