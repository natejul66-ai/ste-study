CSS: Cascading Style Sheets

Learn how CSS is used to style HTML webpages, control their appearance, organize layouts, and create interactive designs.

Not completed

1. What is CSS?

Understand the purpose of CSS before learning its syntax.

CSS stands for Cascading Style Sheets. It is used to control the appearance and layout of HTML elements on a webpage.

Think of it this way:

HTML = structure

CSS = appearance and design

2. HTML vs CSS

They work together, but work differently

HTML

Structure

HTML creates the content and structure of a webpage. Examples include headings, paragraphs, images, links, and buttons.

CSS

Style

CSS changes how those HTML elements look. It can control colors, fonts, spacing, sizes, borders, and layout.

3. CSS Syntax

Every CSS rule follows a basic structure.

CSS SYNTAX 
selector {
  property: value;
}
1

Selector

Selects which HTML element you want to style.

Example: p

2

Property

Specifies what aspect of the element you want to change.

Example: color

3

Value

Specifies what you want the property to be.

Example: blue

4

Declaration

A property and its value together form a CSS declaration.

Example: color: blue;

EXAMPLE 
p {
  color: blue;
  font-size: 20px;
}

4. Three Ways to Add CSS

CSS can be applied to HTML in three main ways.

Method 01

Inline CSS

CSS is written directly inside an HTML element using the style attribute. 

<p style="color: blue;">
  Hello
</p>
Method 02

Internal CSS

CSS is written inside a <style> element in the HTML document. 

<style>
p {
  color: blue;
}
</style>
Method 03

External CSS

CSS is stored in a separate .css file and connected to HTML. 

<link
  rel="stylesheet"
  href="style.css"
>

5. CSS Selectors

Selectors determine which HTML elements receive a style.

Selector Example What it selects
Element p All <p> elements
Class .box Elements with class="box"
ID #title Element with id="title"
Universal * All elements
SELECTOR EXAMPLES 
p {
  color: blue;
}

.box {
  padding: 20px;
}

#title {
  font-size: 30px;
}

* {
  box-sizing: border-box;
}

6. Common CSS Properties

These are some of the most commonly used properties.

1

color

Changes the color of text.

2

background-color

Changes the background color of an element.

3

font-size

Changes the size of text.

4

font-family

Changes the typeface used by text.

5

text-align

Controls horizontal text alignment.

6

border

Adds a border around an element.

7

width / height

Controls the dimensions of an element.

8

border-radius

Rounds the corners of an element.

7. Text Styling

CSS gives you control over how text appears.

TEXT STYLING EXAMPLE 
h1 {
  color: blue;
  font-size: 32px;
  font-family: Arial, sans-serif;
  text-align: center;
}

p {
  font-size: 18px;
  text-align: justify;
}
color: changes the text color.
font-size: changes how large the text is.
font-family: changes the font.
text-align: controls alignment such as left, center, right, or justify.

8. Backgrounds and Borders

These properties help define the appearance of boxes and sections.

EXAMPLE 
.card {
  background-color: #171a21;
  border: 1px solid #282d38;
  border-radius: 15px;
}
1

background-color

Sets the background color of an element.

2

border

Creates a line around an element.

3

border-radius

Rounds the corners of an element.

4

background-image

Allows an image to be used as an element's background.

9. CSS Box Model

Every HTML element can be understood as a box.

The CSS box model consists of four main parts: content, padding, border, and margin.

MARGIN
BORDER
PADDING
CONTENT
1

Content

The actual text, image, or other material inside the element.

2

Padding

The space between the content and the border.

3

Border

The line surrounding the padding and content.

4

Margin

The space outside the border.

10. Padding vs Margin

This distinction is important when controlling spacing.

P

Padding

Creates space inside the element, between the content and its border. 

.box {
  padding: 20px;
}
M

Margin

Creates space outside the element, separating it from other elements. 

.box {
  margin: 20px;
}

11. CSS Units

Units tell CSS how large or how much something should be.

px

Pixels

Often used for fixed sizes.

%

Percentage

Often relative to a containing element.

rem

REM

Relative to the root element's font size.

vh

Viewport Height

Relative to the height of the browser viewport.

vw

Viewport Width

Relative to the width of the browser viewport.

13. Pseudo-classes

Pseudo-classes style an element in a particular state.

:HOVER EXAMPLE 
button {
  background: blue;
}

button:hover {
  background: lightblue;
}
1

:hover

Applies styles when the pointer is over an element.

2

:active

Applies styles while an element is being activated.

3

:focus

Applies styles when an interactive element has focus.

14. CSS Comments

Comments help explain code without affecting the webpage.

CSS COMMENT 
/* This is a CSS comment */

h1 {
  color: blue;
}

Anything between /* and */ is treated as a comment by CSS.

15. Common CSS Mistakes

Watch out for these when writing CSS.

Missing semicolon: color: blue;
Missing braces: CSS rules need { }.
Wrong selector: Make sure your selector matches the HTML element, class, or ID.
Wrong class syntax: CSS uses .classname for classes.
Wrong ID syntax: CSS uses #idname for IDs.

17. Quick Review

Remember these key points.

CSS: Cascading Style Sheets.
Purpose: CSS controls the appearance and layout of HTML.
Syntax: selector { property: value; }
Three methods: Inline, Internal, and External CSS.
Class selector: Uses a period, such as .box.
ID selector: Uses a hashtag, such as #title.
Box Model: Content → Padding → Border → Margin.
:hover: Styles an element when the pointer is over it.
Comments: Written between /* */.
